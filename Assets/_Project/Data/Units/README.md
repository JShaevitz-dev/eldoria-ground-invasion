Unit templates (Eldoria.Units.UnitTemplate) go here: a leader soldier plus members. So far: Field Commander, ISF Rifle Squad, Heavy Weapons Team, Mortar Team, Sagittarius MBT, Olympian Mech, ISF Ranger (ISF); Dragon Hierarch, Dragonborn Squad, Kobold Militia (Draconis Imperialis).
After adding one, put it in its faction's unit list and run Eldoria > Rebuild Unit Catalog so the army builder lists it.
