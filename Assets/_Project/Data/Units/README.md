Unit templates (Eldoria.Units.UnitTemplate) go here: a leader soldier plus members. So far: Field Commander, Master Sergeant Jakoby, Marshal Command Tank, ISF Rifle Squad, Heavy Weapons Team, Mortar Team, Sagittarius MBT, Olympian Mech, ISF Ranger, ISF Boarding Team (ISF); Dragon Hierarch, Dragonborn Squad, Kobold Militia, Dragonborn Skymaster Squad, Tyrant Hover-tank (Draconis Imperialis); Rask Ultima, Rask Rifle Team, Stinger Heavy Robot, Intimidator Medium Robot (Rask).
After adding one, put it in its faction's unit list and run Eldoria > Rebuild Unit Catalog so the army builder lists it.
